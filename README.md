## Client Project Team 3

A Spring Boot application for creating, managing, and delivering quizzes.
Includes both admin features (create quizzes, manage questions, capabilities, dashboard statistics) 
and user-facing quiz taking logic, with in-depth statistics for each 'outcome' or learning criteria.
Users can also create, manage and join teams, creating a team automatically makes them the manager, and they can promote or demote other members and see a summary of team statistics.
The user is able to change any of the details or their account in settings: name, email, phone, password.
The landing page gives an unprotected overview of the service, in addition to being able to preview the quizzes without taking them until logged in.
